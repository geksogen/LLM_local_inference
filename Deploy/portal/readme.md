# ⚡ OpenCode & Strata Engine Cluster Portal

Профессиональный селфсервис-портал в стиле Grafana, предназначенный для управления доступом к LLM API (через шлюз LiteLLM) и мониторинга локального инференс-сервиса Strata Engine в реальном времени.

---

## 🚀 Ключевые возможности

1. **Мониторинг инфраструктуры в реальном времени**
   - Опрос состояния движка (`/health`) и метрик шлюза (`/metrics`).
   - Отображение текущего состояния модели (`Idle`, `Processing`, `Offline`).
   - Динамический счетчик задач в очереди (`В ожидании: N`).

2. **Автоматический Onboarding и генерация ключей**
   - Мгновенная генерация виртуального API-ключа в LiteLLM, привязанного к конкретной модели и ограничению параллельных запросов (`max_parallel_requests`).
   - Автоматическое создание и скачивание конфигурационного файла `opencode_{username}.json`.
   - Встроенные инструкции по размещению конфигурации для **Windows** и **macOS**.

3. **Управление токенами и бюджетом**
   - Безопасная проверка расхода средств по персональному API-ключу (авторизация `Bearer` через LiteLLM `/key/info`).
   - Наглядный прогресс-бар бюджета с цветовой индикацией приближения к лимиту (зеленый $\rightarrow$ желтый $\rightarrow$ красный).
   - Поддержка безлимитных ключей.

4. **Система поддержки пользователей**
   - Удобная форма обратной связи на главной странице для отправки вопросов по работе сервиса.
   - Надежное сохранение всех обращений с помощью базы данных **Redis**.

5. **Защищенная панель администратора**
   - Специальный раздел `/admin/questions` для просмотра поступивших от пользователей вопросов.
   - Надежная защита страницы по паролю (`ADMIN_PASSWORD`) с использованием сессионных Cookies.

6. **Современный UI/UX**
   - Адаптивный дизайн на CSS-переменных с мгновенным переключением **Темной и Светлой темы** (сохранение выбора в `localStorage`).
   - Сетчатая структура карточек, оптимизированная под разработчиков и инженеров.

---

## 🛠️ Технологический стек

- **Бэкенд**: FastAPI (Python)
- **Хранилище данных**: Redis (для персистентности вопросов)
- **Инференс и шлюз**: Strata Engine & LiteLLM
- **Фронтенд**: HTML5, CSS3, Vanilla JavaScript

---

## ⚙️ Конфигурация и переменные окружения

Параметры работы портала настраиваются через переменные окружения или напрямую в коде `portal.py`:

- `LITELLM_URL`: Адрес шлюза LiteLLM (по умолчанию: `http://litellm:4000`)
- `STRATA_URL`: Адрес локального инференс-сервиса Strata Engine
- `ADMIN_PASSWORD`: Пароль для доступа к админ-панели вопросов (по умолчанию: `admin123`)

---

## 🐳 Развертывание в Docker

Портал полностью готов к интеграции в ваш Docker/Docker Compose стек вместе с LiteLLM и Redis:

1. Добавьте сервис портала в ваш `docker-compose.yml`.
2. Запустите контейнеры: `sudo docker compose up -d --build`.
3. Откройте веб-интерфейс в браузере по адресу вашего хоста.
